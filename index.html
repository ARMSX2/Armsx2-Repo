Two channels, one source

Adding the source lists both ARMSX2 iOS, the stable release, and ARMSX2 Nightly, an automated build of the latest code. They install as separate apps and keep separate save states, memory cards and settings, so a nightly cannot disturb a working stable install. Nightly builds are not tested. If you want to play, use the stable release.

Before you start

  • A JIT-capable setup is required for playable performance.
  • You provide your own PS2 BIOS and your own legally dumped discs. Neither ships here.
  • Compatibility varies by device, iOS version, game and sideloading environment.
